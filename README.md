# fase 1 análisis 
El juego trata sobre Max, quien despierta en medio de una infección causada por un virus que hace que las personas se vuelvan agresivas y ataquen a los demás. Lo que parecía ser un día normal se convierte en una situación de peligro en la que Max debe buscar la manera de sobrevivir. 
Se creó un juego en Python utilizando Canvas para desarrollar la parte gráfica. Se programó un menú principal, diferentes modos y dificultades, un sistema de infección, un sistema de pistas y diferentes lugares que el jugador puede explorar. 
También se agregaron botones, escenarios, personajes y elementos visuales para que el juego no fuera solamente de texto. El objetivo final del jugador es conseguir las pistas necesarias, encontrar la cura y detener la infección antes de perder la partida.
El objetivo principal es explorar diferentes lugares, conseguir pistas y encontrar la cura antes de que la infección llegue al 100%. El jugador tendrá que tomar decisiones y avanzar con cuidado para poder completar la misión y detener la propagación del virus.
